# be-browser (BE:browse) 🖱️

**AI에게 "내 브라우저 좀 대신 써줘"라고 시킬 수 있게 해주는 스킬입니다.**

여러분이 매일 쓰는 크롬 브라우저, 이미 회사 사이트에 로그인돼 있죠?
이 스킬을 설치하면 AI(Claude Code)가 **바로 그 브라우저**를 여러분 대신 움직입니다.
새 프로그램을 깔 필요도, 다시 로그인할 필요도 없습니다.

> 비유하자면: AI에게 "내 컴퓨터 마우스와 키보드를 잠깐 빌려주는 것"입니다.
> 로그인 같은 중요한 열쇠는 절대 AI에게 주지 않습니다 — 열쇠는 항상 사람이 갖고 있어요.

---

## 어떨 때 쓰나요? (실제 예제)

### 예제 1 — 일정 등록 심부름 ✅ (실제 검증된 사례)
> **나:** "네이버웍스 캘린더에 다음주 월요일 저녁 6시부터 8시까지 '저녁식사' 일정 만들어줘"
>
> **AI:** 캘린더를 열고 → 일정쓰기를 누르고 → 제목·날짜·시간을 채우고 → 저장한 뒤
> → **진짜 저장됐는지 달력에서 다시 확인**까지 하고 보고합니다.

### 예제 2 — 사내 사이트에서 자료 모으기
> **나:** "회사 컨플루언스에서 우리 팀 주간보고 페이지들 제목과 링크를 표로 정리해줘"
>
> **AI:** 이미 로그인된 브라우저로 들어가서 목록을 읽고 표로 만들어줍니다.
> (아이디·비밀번호를 AI에게 알려줄 필요가 전혀 없습니다!)

### 예제 3 — 반복되는 웹 확인 작업
> **나:** "이 관리자 페이지 열어서 오늘 신규 가입자 수만 알려줘"
>
> **AI:** 페이지를 열고 숫자만 쏙 읽어옵니다. 매일 아침 시키면 매일 해줍니다.

### 이럴 땐 쓰지 마세요 ❌
- 수백 페이지를 긁는 대량 수집 → 전용 스크립트가 맞습니다 (스킬 안에 대안 안내 있음)
- 결제, 계약 동의처럼 되돌리기 어려운 일 → 사람이 직접 하세요

## 설치 방법 (1분이면 끝)

**준비물:** Claude Code가 설치된 Mac. 끝입니다.

터미널을 열고 아래 세 줄을 순서대로 붙여넣으세요:

```sh
git clone https://github.com/Roykoo83/be-browser.git
cd be-browser
./install.sh
```

"설치 완료!"가 나오면 끝입니다. (하는 일: 스킬 폴더를 `~/.claude/skills/`에 복사 — 그게 전부라서 지우고 싶으면 그 폴더만 삭제하면 됩니다.)

## 사용 방법

**그냥 말로 시키면 됩니다.** Claude Code 대화창에 이렇게요:

```
/bebrowse 네이버웍스 캘린더에 내일 오전 10시 팀회의 일정 만들어줘
```

또는 스킬 이름 없이 자연스럽게 "브라우저로 ~~ 해줘"라고 해도
AI가 알아서 이 스킬의 절차를 따릅니다.

### 처음 한 번만 해주는 설정 (내 환경에 따라 하나만)

| 내가 쓰는 환경 | 처음 한 번 할 일 |
|---|---|
| **cmux** 터미널 | 없음. 바로 됩니다 |
| **VSCode, 일반 터미널, Claude/Codex 데스크탑** (Mac) | 크롬 메뉴에서 **보기 > 개발자 > "Apple Events의 자바스크립트 허용"** 켜기 (클릭 두 번). 처음 실행 때 "자동화를 허용하시겠습니까?" 팝업이 뜨면 **허용** |
| Windows 등 그 외 | 스킬 문서의 playwright 안내를 따르세요 (보조 방법) |

## 꼭 알아둘 안전 규칙 🔒

1. **로그인은 항상 사람이 합니다.** AI는 아이디·비밀번호를 묻지도, 입력하지도 않습니다.
   로그인 화면이 나오면 AI가 멈추고 여러분에게 넘깁니다.
2. **저장·제출 같은 "쓰기" 작업은 AI가 두 번 확인합니다** — 누르기 전에 입력값을 검증하고,
   누른 후에 결과 화면을 다시 확인합니다.
3. AI가 브라우저를 움직이는 게 눈에 보입니다. 이상하면 그냥 탭을 닫으세요.

## 이 스킬은 뭐가 다른가요?

browser-use(⭐11만) 같은 유명 도구와 같은 원리로 움직이지만,
**별도 프레임워크 설치 없이 여러분이 이미 로그인해둔 진짜 브라우저**를 씁니다.
그래서 사내 시스템처럼 로그인이 필요한 곳에서 특히 강합니다.
자세한 동작 원리와 고급 사용법은 [`bebrowse/SKILL.md`](bebrowse/SKILL.md)에 있습니다
(AI가 읽는 문서이지만 사람이 읽어도 됩니다).
